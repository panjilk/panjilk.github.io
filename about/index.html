    关于我

    你好，我是 panjilk 👋

    欢迎来到我的个人博客。

    我是一个喜欢学习和探索新技术的人，希望通过持续记录，把零散的知识整理成能够反复查阅的内容，也在这个过程中留下自己的成长足迹。

    关于我

    目前我正在学习编程、网站开发以及各种有趣的计算机技术。我喜欢亲手搭建项目，在实践中发现问题，然后一步一步寻找解决办法。

    这个博客就是我的一个小项目。它使用 Hexo 构建，采用 Quieter 主题，并通过 GitHub Pages 发布。

    我会在这里记录

    • 编程与开发过程中的学习笔记
    • Hexo、GitHub 和网站搭建经验
    • 遇到的问题以及解决方法
    • 实用的软件、工具和资源
    • 日常生活中的思考与收获

    为什么创建这个博客

    我希望这里不仅是保存笔记的地方，也是一个能够见证成长的空间。

    写作可以帮助我梳理思路，也能让我在以后遇到类似问题时快速找到答案。如果这些内容刚好也能帮助到其他人，那就更有意义了。

    关于本站

    本站目前仍在不断完善中，后续会陆续增加新的文章、分类和内容。页面或文章中如果存在不足，我也会随着学习逐步改进。

    感谢你的访问，希望这里的内容能给你带来一点帮助或启发。
